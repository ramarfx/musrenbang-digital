# MusrenAI backend: handoff draft

Status: migration 11-15 dan Edge Function belum dipasang pada production. Lihat MUSRENAI_ACTIVATION_READINESS.md untuk prosedur dan batas terbaru.

Endpoint POST `/functions/v1/musrenai-chat` membutuhkan JWT user Supabase pada Authorization; publishable key saja tidak cukup. Request JSON: `{ "message": "...", "history": [{ "role": "user" | "assistant", "content": "..." }], "client_request_id": "uuid-opsional" }`. Maksimal 1.500 karakter per pesan, enam item riwayat, 12.000 byte payload; jangan kirim data pribadi. Riwayat tidak disimpan permanen.

Respons sukses: `{ "answer": "...", "links": [{ "label": "...", "path": "/...", "requires_auth": true }], "disclaimer": null, "request_id": "uuid" }`. Render answer sebagai teks; navigasi hanya dari links. Error `{ "error": { "code": "...", "message": "...", "request_id": "..." } }`: 400 INVALID_INPUT, 401 AUTH_REQUIRED, 403 ORIGIN_DENIED, 429 RATE_LIMITED/PROVIDER_LIMITED, 503 AI_UNAVAILABLE/AUTH_UNAVAILABLE, 504 AI_TIMEOUT. Platform JWT gateway dapat mengembalikan 401 dengan format Supabase sebelum handler; tangani juga error tersebut.

FAQ di knowledge.ts berstatus DRAFT. Handler fail-closed sampai MUSRENAI_FAQ_APPROVED=true setelah review tim dan MUSRENAI_AI_ENABLED=true (nama lama MUSRENAI_GEMINI_ENABLED) dengan konfigurasi backend lengkap; ini bukan persetujuan deployment. Konfigurasi backend: MUSRENAI_ALLOWED_ORIGIN (satu origin tepat), AI_PROVIDER/AI_MODEL/AI_API_KEY sebagai secret, atau nama lama GEMINI_MODEL/GEMINI_API_KEY untuk preset Gemini. Penyedia OpenRouter, OpenAI, dan gateway OpenAI-compatible dapat dipilih per fitur; lihat `supabase/functions/AI_PROVIDERS.md`. Jangan taruh kunci pada frontend/log. Akses akun, model, dan free tier belum diverifikasi; gunakan provider mock dan data sintetis sebelum persetujuan privasi/provider.

Migration lokal 20261103031212_musrenai_rate_limit.sql harus direview dan disetujui sebelum penerapan remote. Fungsi consume_musrenai_quota hanya untuk service_role, setelah validasi user oleh Auth; tabel private menyimpan UUID dan waktu, tanpa isi percakapan. Batas 5/60 detik, 30/hari WIB per user, 300/hari WIB global sebagai nilai awal pada private.musrenai_settings, dapat diubah melalui jalur administrator tepercaya setelah persetujuan. Kuota pesan dan kuota provider terpisah; setiap percobaan provider termasuk retry memerlukan reservasi bersama. Percobaan gagal tetap dihitung. Baris kedaluwarsa dibersihkan secara lazy pada permintaan berikut; kebijakan retensi/cleanup perlu disetujui. Tidak ada fallback limiter dalam memori. Kuota global berbasis request bukan batas biaya provider. Siapkan budget hard limit provider terpisah sebelum aktif. Provider free tier dapat memakai data untuk peningkatan produk; jangan kirim data warga sebelum keputusan privasi.

Jangan mengaktifkan tanpa menguji Auth HTTP, RLS/grants, concurrency limiter dan Edge Function lokal dengan JWT asli; FAQ harus direview, konfigurasi origin disetujui, dan kontrol deployment/biaya ditinjau. Pengujian sintetis tidak membuktikan model tidak akan berhalusinasi atau mengenali seluruh data pribadi.
